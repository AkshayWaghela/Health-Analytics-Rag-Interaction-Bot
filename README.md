
# 🩺 Health Analytics RAG

A Streamlit-based health analytics chatbot combining:

- Pandas
- FAISS
- Sentence Transformers
- Qwen
- Retrieval-Augmented Generation
- Streamlit

## Features

### Dataset Analytics

The application can calculate:

- Average BMI
- Average sleep
- Average daily steps
- Average heart rate
- Average water intake
- Highest-risk users
- Healthiest users

### User-Level Queries

Examples:

```text
Tell me about user 120

How is user 120 doing?

What is user 120's average sleep?

Tell me about user 2500
